# Interface localization

The workbench uses one UI locale for login, owner and viewer pages, and same-origin embedded task details. `assets/i18n.js` is a public, data-free resource loaded before page scripts. The ES-module bridge is `assets/i18n.mjs`.

## Selection

1. An explicit language query is used when browser storage is unavailable.
2. A valid saved preference overrides automatic selection.
3. System default reads the first language exposed by `navigator.languages`, falling back to `navigator.language`.
4. Chinese language tags select Simplified Chinese. Other languages use English.
5. Embedded details inherit the parent interface language.

The selector stores `auto`, `en` or `zh-CN` under `pm-server:language:v1`. Storage failures do not prevent the interface from loading. A query fallback survives sign-in navigation. Returning to System default restores browser-language detection. Language changes reload the page; task filters keep their existing stored values.

Web pages cannot independently read an operating-system language when the browser exposes a different preference. System default therefore follows the browser's preferred language.

## Translation boundary

- `t` translates explicitly selected UI labels and messages.
- `ui` translates only the literal segments of tagged templates. Interpolated values remain untouched; HTML callers must still escape data normally.
- Static HTML text and accessible attributes are explicitly annotated with `data-i18n` and `data-i18n-attrs`.
- Canonical `value` and `data-*` attributes are preserved. CSV states and filter identities remain Chinese protocol values.
- Task titles, descriptions, project names, authors, evidence and file paths are original user content. Never translate them as a side effect of rendering.
- Known structured error prefixes can be translated while preserving their diagnostic IDs and paths. Unknown technical diagnostics remain in their original form.

There is no document-wide replacement, MutationObserver translation, external translation API or task-file rewrite.

## Verification

`lib/i18n.test.mjs` checks locale selection, storage failures, safe interpolation and canonical attributes. `scripts/i18n-browser-test.mjs` checks actual Chromium behavior, including original user strings that deliberately match translated UI labels. Chinese, sharing and notification regression suites explicitly select Chinese; they no longer rely on a browser's default locale.
